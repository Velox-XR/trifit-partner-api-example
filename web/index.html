What happens behind the scenes?
  1. The browser sends the selected pair to the demo backend.
  2. The backend uploads the images and queues one DressMe request.
  3. The server-only SDK credential calls the Partner API with its registered webhook endpoint.
  4. The backend verifies and durably saves the signed callback, then confirms the result through the authorized API.
  5. The browser reads the demo's saved status and displays your result.

No API or signing key is exposed. Missing webhooks use delayed GET-only recovery, never another generation. Uncertain submissions stop for review. The duration label reports the actual completion source.
