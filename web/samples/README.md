# Existing official Velox examples

These are copies of the public TriFit website's Amara and Mateo examples,
created on 8 October 2026. The personal portraits are owner-approved AI models;
the result images are existing TriFit outputs. The reference images show the
clothing used. No customer library, newly generated image or private media URL
is included.

The demo serves these five boards as selectable local starter products. Use a
separate personal photo; people pictured inside a collage are clothing-reference
content. Selecting a board does not upload or generate anything or bypass consent,
quotas or the existing queue. The normal browser preparation makes a resized copy
if necessary before a visitor submits; the checked-in originals remain unchanged.

These historical examples illustrate the experience; they are not a current
model benchmark or a guarantee of fit, colour or garment fidelity. Do not label
them as a v2.1 test or a competitor comparison.
