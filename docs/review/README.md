# Plugin review walkthrough

The captioned MP4 shows recorded results from real official MCP SDK calls to a local instance of the published read-only documentation server at source d6ba1a2c3e72cb414daccbf2b59a9698e75c9910. It is a sequence of captured reviewer-dashboard screens, not a recording of a ChatGPT conversation. The underlying tool responses are in mcp-acceptance.json.

It covers five positive developer scenarios and three negative scenarios. Private-path and unsupported-language errors were returned by the real tool schema. Key provisioning and benchmark comparison are not exposed capabilities. Expected agent behavior is labelled separately from observed protocol responses.

The tools cannot generate images, issue credentials, access partner accounts or publish applications. All recorded input/output is public documentation; no private photos or API credentials are included. Hosted endpoint validation and public-directory approval are separate release gates.
